# Frontend Design

Build distinctive, production-grade frontend interfaces that avoid generic AI-looking design.

## Use this skill when

- creating a new UI with strong visual identity
- redesigning an existing page or component
- polishing a rough interface
- building a landing page, dashboard, or feature UI

## Do not use this skill when

- the task is mostly backend
- the request is only for logic fixes
- the user wants plain structural markup only

## Core principle

Do not produce generic SaaS-looking UI or default component-library aesthetics.

## Workflow

1. Understand the product context
2. Choose one clear aesthetic direction
3. Define typography, spacing, palette, and motion rules
4. Build working code
5. Refine for polish, usability, and responsiveness

## Design rules

- Make typography intentional
- Use spacing and composition deliberately
- Avoid bland card-grid defaults
- Use motion only when it improves the experience
- Keep the result cohesive and shippable

## Default stack

- React + Vite
- Tailwind CSS
- Semantic HTML
- Accessible interactions
