# Frontend Design

Build distinctive, production-grade frontend interfaces that reject generic, cookie-cutter aesthetics.

## Use this skill when

- building a page, section, or component with strong visual identity
- redesigning an existing UI
- polishing a rough frontend into something more intentional
- creating landing pages, dashboards, or product interfaces

## Do not use this skill when

- the task is mostly backend
- the user only wants logic fixes with no design work
- the user asks for plain utility markup with no styling emphasis

## Core principle

Do not generate generic SaaS-looking UI or default component-library vibes.

## Workflow

1. Infer the product context
2. Choose one clear aesthetic direction
3. Define typography, spacing, palette, and motion rules
4. Build real working code
5. Refine details for polish, responsiveness, and usability

## Design rules

- Commit to a clear visual direction
- Avoid bland card grids and random gradients
- Make typography intentional
- Use spacing and composition deliberately
- Use motion only when it improves the experience
- Keep the result production-grade and shippable

## Stack defaults

- React + Vite
- Tailwind CSS
- Semantic HTML
- Accessible interactions
